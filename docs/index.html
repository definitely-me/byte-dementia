ABOUT

byteDementia is a lightweight CLI application developed in C, designed to provide fast file encryption directly from your terminal. It offers a straightforward approach to securing personal data by utilizing a custom Add-Rotate-Xor cryptographic method. The main concept behind the program is to allow users to easily "corrupt" their sensitive files to make them completely unreadable, and later "revive" them back to their original state. This transformation process is driven by a combination of a user-provided ASCII text password and an automatically generated salt seed, which work together to create a unique 1024-byte key for every single encryption session. Because it operates entirely in-memory and requires minimal setup, byteDementia serves as a highly portable and efficient tool. It is perfect for anyone who needs to quickly lock away important or inappropriate information without depending on heavy or complex software.

KEY FEATURES

Custom ARX Engine
Implements a fast byte-level cipher utilizing Add and XOR operations to securely obscure your data.
Advanced Key Derivation
Performs 500,000 iterations to expand your simple ASCII password and a unique salt into a robust 1024-byte encryption key.
Dynamic Salt Generation
Automatically creates a unique, random 8-byte salt for every session, meaning the same file encrypted twice will result in completely different outputs. Pure random salt thanks to this repo.
Built-in Data Integrity
Calculates a reliable checksum and original file size during encryption to verify file integrity and warn you about incorrect passwords or data loss upon decryption.
Custom File Headers
Embeds a special metadata header into the encrypted files to safely store the salt, original file size, version compatibility, and checksum data.
In-Memory Processing
Loads and encrypts files exclusively within your system's RAM for rapid processing speeds, leaving no unencrypted temporary files on your drive.

WHY DEMENTIA?

I had no idea what my first C project should be. All beginner projects felt boring, so I just put the idea on hold for a while. One day youtube recommended me a video called Everywhere At The End Of Geometry Dash (EATEOT reference, game OST slowly becoming unrecognizable and distorted). It made me realize: every photo, video, or piece of data on your drive only exists because its bytes are arranged in a very specific order. It is a delicate balance. I decided I wanted to break that balance by writing an encryptor. That is how the idea was born, that is why it is called byteDementia.

BUILDING

gcc main.c encrypt.c io.c randombytes.c -o byteDementia -O3 -march=native -flto

Compiled and tested on Arch Linux and macOS Sequoia.
